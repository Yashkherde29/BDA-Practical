# Big Data Analytics & Hadoop Practicals

A collection of seven hands-on academic practicals completed as part of the **Big Data Analytics & Hadoop** subject. These practicals explore machine learning algorithms using Python and Scikit-learn.

## 📚 Practicals Covered

| No. | Practical | Description |
|---|---|---|
| 1 | Logistic Regression | Classification using logistic regression |
| 2 | K-Nearest Neighbors (KNN) | Classification based on nearest data points |
| 3 | Support Vector Machine (SVM) | Classification using support vectors |
| 4 | Decision Tree | Tree-based classification |
| 5 | Random Forest | Ensemble learning using decision trees |
| 6 | Gradient Descent | Model optimization using gradient-based learning |
| 7 | Ensemble Techniques | Combining multiple models for prediction |

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- KaggleHub for dataset access

## 🚀 How to Run

1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn kagglehub
   ```

4. Open a notebook in Jupyter Notebook.
5. Run the cells sequentially.

**Note:** Some notebooks download the dataset through KaggleHub. Internet access may be required, and dataset access must be available.

## 🎯 Learning Objectives

- Understand fundamental machine learning algorithms.
- Practice data preprocessing and model training.
- Explore classification and optimization techniques.
- Gain practical experience with Python-based machine learning workflows.
